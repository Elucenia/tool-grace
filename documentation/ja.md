# GRACEスコア（院内死亡）

[条件・出典・許諾](https://elucenia.org/ja/tools/grace)

## 使い方

ポータルでツールを使用するか、ローカルHTTPサーバー経由でindex.htmlを開いてください。言語を選択し、項目を入力して計算してください。

## 入力項目と単位

### 年齢

`idade`

年 · 範囲: 18–110

### 心拍数

`fc`

拍/分 · 範囲: 20–250

### 収縮期血圧

`pas`

mmHg · 範囲: 40–300

### クレアチニン

`cr`

mg/dL · 範囲: 0.1–20

### Killip分類

`killip`

- `1` — I
- `2` — II
- `3` — III
- `4` — IV

### 入院時心停止

`pcr`

### ST偏位

`st`

### 壊死マーカー上昇（トロポニン/CK-MB）

`enz`

## 方法の版

GRACE/Granger 2003：院内ノモグラム，ローカル補間；GRACE 2.0ではない

## 記載された計算式

ノモグラム点数 (Granger 2003): 年齢 \< 30 = 0, 30–39 = 8, 40–49 = 25, 50–59 = 41, 60–69 = 58, 70–79 = 75, 80–89 = 91, ≥ 90 = 100 · 心拍数 \< 50 = 0, 50–69 = 3, 70–89 = 9, 90–109 = 15, 110–149 = 24, 150–199 = 38, ≥ 200 = 46 · 収縮期血圧 \< 80 = 58, 80–99 = 53, 100–119 = 43, 120–139 = 34, 140–159 = 24, 160–199 = 10, ≥ 200 = 0 · クレアチニン (mg/dL) \< 0.4 = 1, 0.4–0.79 = 4, 0.8–1.19 = 7, 1.2–1.59 = 10, 1.6–1.99 = 13, 2–3.99 = 21, ≥ 4 = 28 · Killip I = 0, II = 20, III = 39, IV = 59 · 心停止 = 39 · ST偏位 = 28 · マーカー上昇 = 14.

死亡確率はノモグラムから読み取る（表の点数間を補間）。

## 限界・対象集団

2003年のGRACEは、急性冠症候群の範囲で入院中の死亡を推定します。元のノモグラム版とローカルの補間は、GRACE 2.0モデルではありません。侵襲的方針、他の時間範囲、リスク率についての判断には、対応するガイドラインと版が必要です。
