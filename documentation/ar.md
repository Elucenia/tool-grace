[الشروط والمصادر والأذونات](https://elucenia.org/ar/tools/grace)

استخدم الأداة في البوابة أو افتح index.html عبر خادم HTTP محلي. اختر اللغة، وأكمل الحقول، ثم أجرِ الحساب.

## المدخلات والوحدات

### العمر

`idade`

سنوات · النطاق: ١٨–١١٠

### معدل ضربات القلب

`fc`

`pas`

## إصدار الطريقة

GRACE/Granger 2003: مخطّط للمستشفى واستيفاء محلي؛ ليس GRACE 2.0

## المعادلة الموثقة

نقاط المخطّط (Granger 2003): العمر \< 30 = 0, 30–39 = 8, 40–49 = 25, 50–59 = 41, 60–69 = 58, 70–79 = 75, 80–89 = 91, ≥ 90 = 100 · معدّل القلب \< 50 = 0, 50–69 = 3, 70–89 = 9, 90–109 = 15, 110–149 = 24, 150–199 = 38, ≥ 200 = 46 · الضغط الانقباضي \< 80 = 58, 80–99 = 53, 100–119 = 43, 120–139 = 34, 140–159 = 24, 160–199 = 10, ≥ 200 = 0 · الكرياتينين (mg/dL) \< 0.4 = 1, 0.4–0.79 = 4, 0.8–1.19 = 7, 1.2–1.59 = 10, 1.6–1.99 = 13, 2–3.99 = 21, ≥ 4 = 28 · Killip I = 0, II = 20, III = 39, IV = 59 · توقّف القلب = 39 · انحراف ST = 28 · ارتفاع الواسمات = 14.

يُقرأ احتمال الوفاة من المخطّط (بالاستيفاء بين النقاط المدرجة).

## الحدود والفئة السكانية

تقدّر GRACE لعام 2003 الوفاة أثناء الاستشفاء في طيف المتلازمة التاجية الحادة. لا تمثل النسخة الأصلية المعتمدة على النوموغرام والاستيفاء المحلي نموذج GRACE 2.0. تتطلب قرارات الاستراتيجية الباضعة أو الأطر الزمنية الأخرى أو معدلات الخطر الدليل الإرشادي والإصدار المقابلين.

## إعادة إجراء الاختبارات التقنية

شغّل node test.cjs في المجلد الجذري لهذا المستودع لتكرار الحالات الاصطناعية المسجلة. تُحفظ المدخلات والنتائج المتوقعة وحدود التفاوت الأصلية. لا تُعدّ الاختبارات التقنية تحققًا سريريًا.

```sh
node test.cjs
```

يحتوي tool.json على المصادر والإصدار ونطاق المراجعة. يحتفظ examples.json بالمدخلات والنتائج المتوقعة للحالات الاصطناعية؛ ويسجل results.json النتائج التي تم الحصول عليها.

## المراجعة وشروط الاستخدام

لم تُجرَ مراجعة سريرية مستقلة.

هذه الواجهة ترجمة أعدّها مؤلفوها، وليست إصدارًا رسميًا أو معتمدًا. لم تُجرَ مراجعة سريرية مستقلة أو مراجعة لغوية مهنية، ولم تُستكمل الموافقة على حقوق استخدام الأدوات.

نتيجة المعادلة أو التصنيف. يعتمد التفسير والتصرف ومدى الانطباق على التقييم المهني والمصدر المحدد.
